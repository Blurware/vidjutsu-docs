## Level clips

`POST /projects/{project}/level` measures what each clip on the audio tracks you name actually plays (EBU R128), then sets each clip's gain so it plays at the `target` loudness. It's applied as one edit, so it makes a new revision like any other.

```sh
curl -s -X POST https://api.vidjutsu.ai/projects/launch-film/level \
  -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"tracks": ["a1"], "target": -16}'
```

```json
{"clips": [{"occurrence": "t1-sound", "measured_lufs": -22.4, "gain_db": 6.4, "true_peak": -3.1, "peak_limited": false}, ...],
 "edit": {"project": "launch-film", "branch": "main", "parent": "...", "revision": "...", "target_lufs": -16}}
```

| Field | Default | |
| --- | --- | --- |
| `tracks` | required | Audio track ids to level. |
| `target` | `-16` | Loudness each clip should play at, in LUFS. |
| `max_peak` | `-1` | True-peak ceiling, in dBTP. A clip that would clip is held below it (`peak_limited`). |
| `branch` | `main` | |
| `dry_run` | `false` | Measure and report without editing. |

Leveling sets clip gain. To set the loudness of the finished film, pass `loudness` when you [render](/guides/rendering#options).

## Clean up voice

[Studio Sound](/guides/studio-sound) cleans every voice in a project in one step (noise, echo, tone and level) and swaps the cleaned copies onto their clips as one revision. It costs $0.10 a voice minute, billed by the second.
