## Authentication

Send an API key as a bearer token on every call:

```
Authorization: Bearer vj_live_...
```

Get one with [two sign-up calls](/authentication). OAuth access tokens from MCP sign-in work too. `GET /health`, `POST /auth/email` and `POST /auth/verify` need no key.

## Versioning

The API is versioned by date, like Stripe. Paths carry no version. Instead, every request names the version it was written against in a header:

```
VidJutsu-Version: 2026-11-03
```

The current version is `2026-11-03`.

- **Pin a version.** Send the header on every request, so your code keeps working when a new version ships. A request without it gets the latest version.
- **Every response says which version served it**, in its own `VidJutsu-Version` header.
- **An unknown version** is a 400 `invalid_request` with `reason: "unknown_version"` and the `latest_version`.
- **What gets a new version.** A change that could break existing code ships under a new date, and requests that name an older date keep the old behavior. Additive changes (new operations, new optional fields, new response fields) don't get a new version and reach every version, so read responses leniently.

The CLI and SDK send the version they were built for. In the SDK, pass `apiVersion` to pin another one.

## Conventions

- **JSON in, JSON out**, with snake_case fields. Send `Content-Type: application/json`. The one exception is `POST /media`, which also takes up to 4 MB of raw bytes as `application/octet-stream`.
- **Idempotency.** Send an `Idempotency-Key` header on every write. A retry with the same key returns the first result instead of doing the work twice. For edits, also send `expected_head`.
- **Times** in timelines are exact: whole seconds, decimal strings (`"12.5"`) or fractions. See [Times](/guides/editing#times).
- **Renders are background jobs**, and so are previews, transcripts, Studio Sound, frame and check. Starting one answers with a job; poll `GET /jobs/{job_id}`, or follow the project's [live stream](/guides/live-updates).
- **Who is acting.** Send `VidJutsu-Client: <name>` (for example `Claude Code`) and history, Activity and change notices name you that way. Without it, you're named by your API key's name. It's display only and grants nothing.
- **ETags.** `GET /projects/{project}` and `GET /projects/{project}/head` send an `ETag`. Send it back as `If-None-Match` and an unchanged project answers 304 with no body.
- **Errors** have a stable `code`, a `message`, and fields that tell you how to fix them. See [Errors](/errors).
- **Every operation is also an MCP tool** with the same name (the `operationId` on each page). See [MCP](/mcp).

## Operations

| Group | Operations |
| --- | --- |
| Sign-up and sign-in | `POST /auth/email`, `POST /auth/verify` |
| Account | `GET /account`, `POST /account`, `GET /usage`, `GET /entitlements` |
| API keys | `GET /keys`, `POST /keys`, `DELETE /keys/{key_id}` |
| Billing | `POST /billing/checkout`, `POST /billing/top-up`, `POST /billing/auto-top-up`, `POST /billing/portal`, `GET /wallet`, `GET /projects/{project}/quote` |
| Media | `POST /media`, `GET /media/{hash}`, `GET /media/{hash}/url`, `POST` and `GET /media/{hash}/preview`, `POST` and `GET /media/{hash}/transcript` |
| Uploads | `POST /uploads`, `POST /uploads/{upload_id}/complete`, `DELETE /uploads/{upload_id}` |
| Projects | `GET /projects`, `POST /projects`, `GET /projects/{project}`, `GET /projects/{project}/head`, `POST /projects/{project}/edits`, `GET /projects/{project}/timeline-words` |
| History | `GET /projects/{project}/history`, `POST /projects/{project}/undo`, `POST /projects/{project}/restore` |
| Shot list | `GET /projects/{project}/shot-list`, `POST /projects/{project}/shot-list/edits`, `GET /projects/{project}/files`, `GET /projects/{project}/words` |
| Layouts | `GET /layouts`, `POST /layouts`, `DELETE /layouts/{layout_id}`, `POST /projects/{project}/layout` |
| Audio | `POST /projects/{project}/studio-sound`, `POST /projects/{project}/level` |
| Live updates | `GET /projects/{project}/events`, `POST /projects/{project}/presence`, `POST /projects/{project}/working_on` |
| Comments | `GET` and `POST /projects/{project}/comments`, `POST` and `DELETE /projects/{project}/comments/{comment_id}` |
| Renders | `POST /projects/{project}/renders`, `GET /jobs/{job_id}`, `POST /jobs/{job_id}/cancel` |
| Status | `GET /health` |
