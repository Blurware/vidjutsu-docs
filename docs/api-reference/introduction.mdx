## Authentication

Send an API key as a bearer token on every call:

```
Authorization: Bearer vj_live_...
```

Get one with [two sign-up calls](/authentication). OAuth access tokens from MCP sign-in work too. `GET /v3/health`, `POST /v3/auth/email` and `POST /v3/auth/verify` need no key.

## Conventions

- **JSON in, JSON out**, with snake_case fields. Send `Content-Type: application/json`. The one exception is `POST /v3/media`, which also takes up to 4 MB of raw bytes as `application/octet-stream`.
- **Idempotency.** Send an `Idempotency-Key` header on every write. A retry with the same key returns the first result instead of doing the work twice. For edits, also send `expected_head`.
- **Times** in timelines are exact: whole seconds, decimal strings (`"12.5"`) or fractions. See [Times](/guides/editing#times).
- **Renders are background jobs.** `POST /v3/projects/{project}/renders` answers 202 with a job; poll `GET /v3/jobs/{job_id}`.
- **Errors** have a stable `code`, a `message`, and fields that tell you how to fix them. See [Errors](/errors).
- **Every operation is also an MCP tool** with the same name (the `operationId` on each page). See [MCP](/mcp).

## Operations

| Group | Operations |
| --- | --- |
| Sign-up and sign-in | `POST /v3/auth/email`, `POST /v3/auth/verify` |
| Account | `GET /v3/account`, `POST /v3/account`, `GET /v3/usage`, `GET /v3/entitlements` |
| API keys | `GET /v3/keys`, `POST /v3/keys`, `DELETE /v3/keys/{key_id}` |
| Billing | `POST /v3/billing/checkout`, `POST /v3/billing/portal` |
| Media | `POST /v3/media`, `GET /v3/media/{hash}`, `GET /v3/media/{hash}/url` |
| Uploads | `POST /v3/uploads`, `POST /v3/uploads/{upload_id}/complete`, `DELETE /v3/uploads/{upload_id}` |
| Projects | `POST /v3/projects`, `GET /v3/projects/{project}`, `POST /v3/projects/{project}/edits` |
| Audio | `POST /v3/projects/{project}/level`, `POST /v3/audio/clean` |
| Renders | `POST /v3/projects/{project}/renders`, `GET /v3/jobs/{job_id}`, `POST /v3/jobs/{job_id}/cancel` |
| Status | `GET /v3/health` |
