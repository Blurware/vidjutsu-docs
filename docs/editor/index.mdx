VidJutsu Editor is a native Mac app for VidJutsu Cloud, for the part of editing you want to see for yourself. Your agent does the cutting through VidJutsu Cloud; the editor is where you read the script, watch the cut, say what to change and approve it.

## What it does

- **Review by transcript.** Read the cut as a script next to the video, and mark what to cut or keep.
- **Watch the timeline.** Scrub and play the current cut on a timeline with thumbnails and waveforms.
- **Comment on moments.** Leave a comment pinned to a stretch of the cut, then mark it approved or needing changes. Comments left on an earlier revision are labeled as such.
- **Chat with an agent.** Ask for changes in plain words. The built-in agent edits and renders with the same operations as the [API](/api-reference/introduction), the [CLI](/cli/index) and [MCP](/mcp), so its work shows up wherever you look.
- **Record takes.** Record your screen, camera and microphone and upload the take straight into a project.

## What you need

- **A Mac with macOS 15 (Sequoia) or later**, Apple silicon or Intel.
- **A VidJutsu Cloud account.** The editor doesn't work without one: all video work (uploads, storage, renders) runs on VidJutsu Cloud and is paid from your [wallet](/pricing). It uses the same API key as the CLI, so if you've run `vidjutsu login` you're already signed in. New here? [Sign up](/quickstart) first.
- **An AI model for chat**, any one of:
  - Sign in with ChatGPT.
  - Your own OpenAI API key.
  - Your own Anthropic API key.

  You don't need any of these to edit by hand.

<Tip>

## Install

1. [Download VidJutsu Editor](https://download.vidjutsu.ai/editor/VidJutsu-Editor.dmg).
2. Open the DMG and drag **VidJutsu Editor** to **Applications**.
3. Open it from Applications. It's signed and notarized by Apple, so it opens without a warning.

The app updates itself: it checks once a day, and you can check any time with **Check for Updates…** in the app menu or the **Updates** tab in Settings.

Want a specific version? Each release is also published under its version number, for example [VidJutsu-Editor-0.1.0.dmg](https://download.vidjutsu.ai/editor/VidJutsu-Editor-0.1.0.dmg). [`latest.json`](https://download.vidjutsu.ai/editor/latest.json) gives the latest version, its SHA-256 and size.
