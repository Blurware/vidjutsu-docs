VidJutsu Editor is a free, native Mac app for the part of editing you want to see for yourself. Your agent does the cutting through VidJutsu Cloud; the editor is where you read the script, watch the cut, say what to change and approve it.

## What it does

- **Edit by transcript.** Every take comes with a word-level transcript. Read the cut as a script, and select words to cut, keep or comment on them.
- **Watch the timeline.** Scrub and play the current cut on a timeline with thumbnails and waveforms. Every edit is a new revision, so you can step back to an earlier version.
- **Comment on moments.** Select a stretch of transcript to leave a comment pinned to that time range, then mark the cut approved or needing changes.
- **Chat with an agent.** Ask for changes in plain words. The built-in agent edits and renders with the same operations as the [API](/api-reference/introduction), the [CLI](/cli/index) and [MCP](/mcp), so its work shows up wherever you look.
- **Record takes.** Record your screen, camera and microphone and upload the take straight into a project.

## What you need

- **A Mac.**
- **A VidJutsu Cloud account.** All video work (uploads, storage, renders) runs on VidJutsu Cloud and is paid from your [wallet](/pricing). The app itself is free. It uses the same API key as the CLI, so if you've run `vidjutsu login` you're already signed in.
- **An AI model for chat**, any one of:
  - Sign in with ChatGPT.
  - Your own OpenAI API key.
  - Your own Anthropic API key.

  You don't need any of these to edit by hand.

<Tip>
  Prefer your own agent? Claude Code, Claude Desktop, Cursor or any MCP client can drive the same projects through [MCP](/mcp) while the editor shows the result.
</Tip>
