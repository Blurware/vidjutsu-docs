title: "Quickstart"
description: "Sign up, subscribe, upload a take and render your first cut."
---

You need an email address and a card. There is no free plan: Pro is $25 a month plus usage, with 60 minutes of 1080p rendering included each month. See [Pricing](/pricing).

<Tabs>
  <Tab title="CLI">

<Steps>
  <Step title="Install">
    ```sh
    npm i -g vidjutsu
    # or a standalone binary for macOS and Linux:
    curl -fsSL https://vidjutsu.ai/install.sh | sh
    ```
  </Step>
  <Step title="Sign up">
    ```sh
    vidjutsu login
    ```
    Enter your email, then the code we send you. This creates your account and saves an API key to `~/.config/vidjutsu/cloud.json`. Signing in again later works the same way.
  </Step>
  <Step title="Subscribe">
    ```sh
    vidjutsu billing checkout
    ```
    Open the `url` it prints and pay with Stripe. Your account turns `active` as soon as checkout completes (`vidjutsu account` shows it).
  </Step>
  <Step title="Upload a take">
    ```sh
    vidjutsu upload take1.mp4
    ```
    It prints the media item. A video with sound gives you two: `take1` (the picture) and `take1-audio` (its sound). Keep the printed `media` and `audio` objects for the next step.
  </Step>
  <Step title="Make a project and edit it">
    ```sh
    vidjutsu init first-cut
    vidjutsu edit first-cut edit.json
    ```
    `edit.json` places the first 20 seconds of the take on the timeline with its sound. Paste the `media` and `audio` objects from the upload where marked:

    ```json edit.json
    [
      {"op": "add_media", "media": {"id": "take1", "...": "the media object from upload"}},
      {"op": "add_media", "media": {"id": "take1-audio", "...": "the audio object from upload"}},
      {"op": "insert_clip", "track_id": "v1", "occurrence": {
        "id": "c1", "media_id": "take1", "timeline_start": 0,
        "source": {"start": 0, "end": 20},
        "layout": {"x": 0, "y": 0, "width": 1000, "height": 1000}}},
      {"op": "insert_clip", "track_id": "a1", "occurrence": {
        "id": "c1-sound", "media_id": "take1-audio", "timeline_start": 0,
        "source": {"start": 0, "end": 20}}}
    ]
    ```
  </Step>
  <Step title="Render">
    ```sh
    vidjutsu render first-cut --out first-cut.mp4
    ```
    It waits for the render job and saves the file. Add `--json '{"height": 2160}'` for 4K.
  </Step>
</Steps>

  </Tab>
  <Tab title="curl">

<Steps>
  <Step title="Sign up">
    ```sh
    API=https://api.vidjutsu.ai
    curl -s -X POST $API/v3/auth/email -H 'Content-Type: application/json' \
      -d '{"email": "you@example.com"}'
    # {"attempt": "...", "expires_at": "...", "next": "POST /v3/auth/verify ..."}

    curl -s -X POST $API/v3/auth/verify -H 'Content-Type: application/json' \
      -d '{"attempt": "...", "code": "123456"}'
    # {"api_key": "vj_live_...", "account_id": "...", "status": "no_plan", "checkout_url": "https://checkout.stripe.com/..."}
    ```
    Keep the `api_key`: it's shown once.
  </Step>
  <Step title="Subscribe">
    Open `checkout_url` in a browser and pay. Then check:
    ```sh
    KEY=vj_live_...
    curl -s $API/v3/account -H "Authorization: Bearer $KEY"
    # {"account_id": "...", "status": "active", ...}
    ```
  </Step>
  <Step title="Add a take">
    For a file that's already online, send its https link. For files on your machine, use a [direct upload](/guides/uploads).
    ```sh
    curl -s -X POST $API/v3/media -H "Authorization: Bearer $KEY" \
      -H 'Content-Type: application/json' \
      -d '{"url": "https://example.com/take1.mp4"}'
    # {"name": "take1.mp4", "media": {"id": "take1", ...}, "audio": {"id": "take1-audio", ...}, ...}
    ```
  </Step>
  <Step title="Make a project and edit it">
    ```sh
    curl -s -X POST $API/v3/projects -H "Authorization: Bearer $KEY" \
      -H 'Content-Type: application/json' -d '{"project": "first-cut"}'

    curl -s -X POST $API/v3/projects/first-cut/edits -H "Authorization: Bearer $KEY" \
      -H 'Content-Type: application/json' -d @edit.json
    ```
    Use the `edit.json` from the CLI tab, with the `media` and `audio` objects from the previous step.
  </Step>
  <Step title="Render and download">
    ```sh
    curl -s -X POST $API/v3/projects/first-cut/renders -H "Authorization: Bearer $KEY" \
      -H 'Content-Type: application/json' -H 'Idempotency-Key: first-cut-1' -d '{}'
    # 202 {"job_id": "rj_...", "state": "queued", ...}

    curl -s $API/v3/jobs/rj_... -H "Authorization: Bearer $KEY"
    # poll until "state": "succeeded"; then output.url is a 7-day download link
    ```
  </Step>
</Steps>
